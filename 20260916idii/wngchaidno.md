# 【科研突破】第904医院神经外科合作发现胶质母细胞瘤进展新机制，成果登顶《Cancer Cell》！

> 更新时间：2026-09-16 (UTC+8)

近日，第904医院神经外科王玉海教授团队与陆军军医大学西南医院卞修武院士、冯华教授团队合作，在国际顶级肿瘤学期刊《Cancer Cell》（影响因子48.8）上发表题为《Long-range Cholinergic Input Promotes Glioblastoma Progression》的重要研究论文，系统揭示了远距离胆碱能神经输入在促进胶质母细胞瘤进展中的关键作用。

**研究背景与意义**

胶质母细胞瘤（Glioblastoma, GBM）是最常见的原发性恶性脑肿瘤，五年生存率不足10%，因其高侵袭性和有限治疗手段，被称为“癌中之王”。该肿瘤进展与中枢神经系统微环境密切相关，尤其神经元与肿瘤细胞之间的交互作用近年来备受关注，但其全脑范围内的神经环路调控机制仍不明确。

**创新发现**

研究团队综合运用伪狂犬病毒逆行示踪、免疫电镜、光遗传学、化学遗传学、钙成像及原位杂交等前沿技术，首次在全脑尺度绘制了神经元-GBM细胞连接图谱，并从神经环路层面阐明胆碱能系统远程调控GBM进展的新机制。

该研究不仅揭示多种神经递质对肿瘤行为的作用，还发现抗胆碱药物东莨菨碱具备抗GBM潜力（“老药新用”），同时提示临床常用乙酰胆碱酯酶抑制剂可能加速GBM进展，为“癌症神经科学”领域提供了新的理论依据和干预策略。

医院王玉海主任为该论文共同通讯作者，杨阳主治医师为第一作者，杨理坤主任为该论文提供了重要指导。

**期刊简介**

《Cancer Cell》创刊于2002年，是一个综合性的癌症研究期刊，由细胞出版社出版。专注于发表具有广泛影响力的肿瘤学原创研究，涵盖癌症生物学、治疗及转化医学等多个前沿方向。期刊最新影响因子为48.8，稳居JCR分区Q1区，是世界肿瘤学研究领域的权威学术平台。
